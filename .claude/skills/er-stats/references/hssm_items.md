## 권장 추출 세트

### A. 기간 종합 리포트 (예: 8/1~8/29)

항목별 구성비가 필요한 12개. 각각 조회 후 `파일`로 내보내 한 폴더에 모은다.

```
응급실현황-내원현황      월별내원환자최초분류현황
응급실현황-주야간별현황  월별내원환자수정분류현황
월별내원시간대           내원수단별
★체류시간 별 총 통계현황 내원경로별
진료결과별               내원사유별
주진료과별               의도성별
```

여기에 `★응급실 종합통계`를 함께 뽑으면 총괄 수치 대조에 쓸 수 있다.

### B. 매일 저녁 집계

```
응급실현황-내원현황
응급실현황-주야간별현황
진료결과별
응급실평균체류시간1
```

### C. 매월 집계

```
★응급실 종합통계
월별내원환자현황
월별내원환자최초분류현황 / 수정분류현황
월별내원시간대
월별시간대퇴실현황
월별업무일지(7시기준)
외부에서전원 / 타기관으로전출
```

## 파일명 규칙

`summary` 모드는 **파일명을 리포트 섹션 제목으로 쓴다.** 항목명 그대로 저장한다.

```
exports/2026-08/
├── 응급실현황-내원현황.csv
├── 내원수단별.csv
├── 진료결과별.xlsx
└── 월별내원시간대.csv
```

`★`, `/`, 공백은 파일명에서 문제를 일으킬 수 있으니 `★`는 빼고 저장한다.

## 원장(raw) 자료가 더 나은 이유

항목별로 10여 번 조회하는 대신 **1행 = 1내원(또는 1처방)** 형태의 원장을 한 번만 받으면
`raw` 모드가 위 항목을 모두 자동 집계하고, 교차 분석(예: KTAS별 체류시간)도 가능하다.
필요한 컬럼은 최소 `내원일시`이고, 나머지는 있는 만큼 집계된다.
