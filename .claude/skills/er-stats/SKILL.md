# 응급실 통계 (통계)

HSSM `부서별 대장 조회 > 통계 탭 > 종류: OCS > 응급실-통계` 항목들을 하나의 기간 리포트로 정리한다.

## 중요: 먼저 확인할 것

**HSSM 클라이언트는 Claude가 직접 조작할 수 없다.** 병원 내부망의 Windows 응용프로그램이므로
`조회` 버튼을 누르거나 항목을 클릭하는 일은 사용자가 해야 한다.
Claude가 하는 일은 **내보낸 파일을 받아 집계·정리**하는 것이다.

따라서 데이터 파일이 없으면 **수치를 추정하거나 만들어내지 말고**, 아래 "1단계"의
추출 절차를 안내하고 파일을 요청한다. 임상 통계를 지어내는 것은 어떤 경우에도 하지 않는다.

## 1단계 — HSSM에서 자료 추출 (사용자 수행)

1. `부서별 대장 조회` 실행 → 좌측 **통계** 탭 클릭
2. **종류**: `OCS` 선택 → `새로고침`
3. 트리에서 **응급실-통계** 폴더 확장
4. 필요한 항목 선택 → **기간을 시작일~종료일로 지정** → `조회`
5. 결과가 뜨면 상단 **`파일`** 버튼으로 내보내기 (CSV 또는 Excel)
6. 파일명은 항목명 그대로 저장 (예: `내원수단별.csv`) — 리포트 섹션 제목으로 쓰인다
7. 한 폴더(예: `exports/2026-08/`)에 모아 Claude에게 전달

항목 목록과 권장 세트는 `references/hssm_items.md` 참고.

> 원장(1행=1내원 또는 1처방) 형태로 한 번에 받을 수 있으면 그 편이 낫다.
> 항목별로 여러 번 조회할 필요 없이 모든 항목이 자동 집계된다.

## 2단계 — 집계 실행

의존성: `pandas`, `openpyxl` (`pip install pandas openpyxl`)

### 원장 자료를 받은 경우 (권장)

```bash
python3 scripts/er_stats.py raw <파일...> --start 2026-08-01 --end 2026-08-29 --out reports/
```

원자료에서 아래 항목을 **자동으로** 집계한다 (해당 컬럼이 있는 항목만):

| 구분 | 산출 항목 |
|---|---|
| 시계열 | 일자별 추이, 요일별, 시간대별, 주야간별 |
| 환자 특성 | 연령대별(평균·중앙값 포함), 성별 |
| 중증도 | 최초분류(KTAS)별, 수정분류(KTAS)별 |
| 내원 | 내원수단별, 내원경로별, 내원사유별, 의도성별, 119지역별 |
| 진료 | 주진료과별, 진료결과별, 주호소·진단별 |
| 처방 | 처방구분별, 처방항목별 |
| 체류 | 평균·중앙값·75/95분위 재실시간, 체류시간 구간별 |

컬럼명은 별칭 사전으로 자동 인식한다(`접수일시`/`내원일시`/`처방일자` 등 혼용 가능).
인식 결과는 실행 끝에 `인식된 컬럼:` 으로 출력되니 **항상 확인하고 사용자에게 보고**한다.
인식 못 한 컬럼이 있으면 `scripts/er_stats.py`의 `ALIASES`에 실제 헤더명을 추가한다.

### HSSM 항목별 집계표를 받은 경우

```bash
python3 scripts/er_stats.py summary exports/2026-08/ --start 2026-08-01 --end 2026-08-29
```

HSSM이 이미 산출한 표를 **재계산 없이 그대로** 하나의 리포트로 병합한다.
파일명이 섹션 제목이 되고, 목차가 자동 생성된다.

### 기간 지정

`--start`/`--end`를 직접 주거나 프리셋을 쓴다.

| 프리셋 | 기간 | 용도 |
|---|---|---|
| `--period daily` | 어제 하루 | 매일 저녁 정기 집계 |
| `--period weekly` | 최근 7일 | 주간 보고 |
| `--period monthly` | 지난달 1일~말일 | 매월 정기 집계 |
| `--period mtd` | 이번 달 1일~오늘 | 월중 누계 확인 |
| `--period all` | 자료 전체 범위 | 기간 미지정 시 기본 |

기타 옵션: `--top N`(값이 많은 항목의 상위 N개, 기본 20), `--title`, `--no-csv`

## 3단계 — 결과 전달

출력물은 두 가지다.

- `reports/er_stats_YYYYMMDD_YYYYMMDD.md` — 항목별 표가 모두 담긴 Markdown 리포트
- `reports/er_stats_YYYYMMDD_YYYYMMDD/NN_<항목>.csv` — 항목별 CSV (Excel용 BOM 포함)

사용자에게 보고할 때는:

1. 총 내원 건수·일평균·기간을 먼저 한 줄로 요약
2. 눈에 띄는 항목 2~3개만 짚는다 (최다 내원일, KTAS 구성, 체류시간 등)
3. 전체 표는 리포트 파일로 넘기고 대화창에 전부 붙여넣지 않는다
4. **날짜 파싱 실패로 제외된 행**이 있으면 반드시 함께 보고한다

## 정기 실행 (매일 저녁 / 매월)

이 스킬은 반복 실행을 전제로 만들었다. 정기 집계를 요청받으면:

- **매일 저녁**: 그날(또는 어제) 자료를 내보낸 뒤 `--period daily`로 집계
- **매월**: 전월 마감 후 `--period monthly`로 집계

스케줄은 `create_trigger`(Routines)로 등록한다. 예시 프롬프트:

> "응급실 통계 스킬로 어제(daily) 집계를 실행하고, 새 내보내기 파일이 없으면
>  사용자에게 HSSM 추출을 요청하는 알림만 남긴다."

cron은 UTC 기준이다. **한국시간(KST, UTC+9) 변환에 주의**한다.

| 원하는 시각(KST) | cron (UTC) |
|---|---|
| 매일 저녁 19:00 | `0 10 * * *` |
| 매일 저녁 21:00 | `0 12 * * *` |
| 매월 1일 09:00 | `0 0 1 * *` |

자동 실행이라도 **자료 파일이 없으면 통계를 만들어내지 않는다.** 파일이 없다는 사실과
추출 절차를 안내하는 것으로 끝낸다.

## 개인정보 주의

응급실 원장에는 환자 식별정보가 포함된다.

- 리포트에는 **집계값만** 싣는다. 환자번호·성명·상세 진단 원문을 그대로 옮기지 않는다.
- 원자료 파일을 저장소에 커밋하지 않는다 (`.gitignore`에 `reports/`, `exports/`, `*.xlsx` 등록됨).
- 셀 건수가 매우 적은 항목(1~2건)은 재식별 위험이 있으므로 필요 시 사용자에게 마스킹 여부를 확인한다.
