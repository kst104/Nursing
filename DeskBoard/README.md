# DeskBoard – 바탕화면 파일 게시판

모니터1(주 모니터) **우측 상단**에 갈색 코르크 보드판 위젯을 띄웁니다.
자주 쓰는 파일을 최대 **8개(4열 × 2행)** 까지 핀으로 꽂아두고 바로 열 수 있습니다.

## 실행

1. Python 3 설치 (https://www.python.org, 설치 시 "Add python.exe to PATH" 체크)
2. (선택) 탐색기에서 끌어다 놓기 기능:
   ```
   pip install tkinterdnd2
   ```
3. `DeskBoard.bat` 더블클릭

## 사용법

| 동작 | 방법 |
|---|---|
| 파일 게시 | `+ 파일` 버튼, 또는 탐색기에서 보드로 드래그 (tkinterdnd2 설치 시) |
| 파일 열기 | 카드 더블클릭 |
| 폴더에서 보기 / 순서 변경 / 떼기 | 카드 우클릭 |
| 위치 이동 | 상단 제목줄을 드래그 |
| 항상 위에 표시 / 위치 초기화 / 종료 | 상단 제목줄 우클릭 |

- 원본 파일은 옮기거나 복사하지 않고 **경로만** 기억합니다. 원본이 이동·삭제되면 카드가 회색으로 표시됩니다.
- 게시 목록은 `%APPDATA%\DeskBoard\board.json` 에 저장되어 다시 실행해도(재부팅 후에도) 유지됩니다. 게시·삭제·이동할 때마다 즉시 저장됩니다.

## 윈도우 시작 시 자동 실행

`DeskBoard.bat` 을 **한 번만** 실행하면, 이후 컴퓨터를 껐다 켜도 로그인할 때 자동으로 게시판이 뜹니다.
(현재 사용자 레지스트리 `HKCU\...\Run` 에 등록, 관리자 권한 불필요)

- 끄기/켜기: 상단 제목줄 우클릭 → **윈도우 시작 시 자동 실행**
- 폴더를 옮긴 경우: 새 위치에서 `DeskBoard.bat` 을 한 번 실행하면 경로가 갱신됩니다.
